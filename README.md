# My Tasks PWA v0.1

iPhone向け個人用タスク管理PWAです。HTML/CSS/JavaScriptのみで動作します。

## 使い方
1. このフォルダーのファイルをすべて、HTTPS対応の静的ホスティング（GitHub Pages、Netlifyなど）にアップロードします。
2. iPhoneのSafariで公開URLを開き、共有メニューから「ホーム画面に追加」を選択します。
3. ホーム画面のMy Tasksを起動します。

※ ZIPをiPhoneで開くだけではPWAのオフライン機能・インストール機能は動きません。HTTPSでの配信が必要です。

## 実装済み
- 日付移動と当日の進捗
- 完了タスクを取り消し線付きで保持
- 日付ごとの独立タスク（ローカルストレージ）
- 平日（月〜金）の繰り返しテンプレートを日付閲覧時に生成
- タスクの追加・編集（名前タップ）・削除
- 初期テンプレート：明日のSalesforce、症例終了伝達、メール既読
- Service Workerによるキャッシュ（初回オンライン読み込み後）

## 制限事項
- 平日テンプレートは選択日以降に適用されます。日付ごとの履歴は独立します。
- テンプレート自体の編集・停止機能は未実装です。テンプレートから生成されたタスクの削除は、同じ日を再表示すると再生成される場合があります。
- 保存先はブラウザのlocalStorageです。データ消去や端末移行では失われる可能性があります。
- 通知、同期、バックアップ、App Store公開は未実装です。
